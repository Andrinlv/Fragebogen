Schriften / Fonts
=================

Diese Verzeichnis enthaelt lokal gehostete Web-Schriften, damit die Applikation
keine Anfragen an Dritte stellt (Datenschutz) und auch in abgeschotteten
Netzwerken sowie offline korrekt rendert.

  inter-latin.woff2 / inter-latin-ext.woff2
      Inter (variable, 300-800) — Copyright (c) 2016-2020 The Inter Project Authors
      https://github.com/rsms/inter

  jetbrains-mono-latin.woff2 / jetbrains-mono-latin-ext.woff2
      JetBrains Mono (variable, 400-700) — Copyright (c) 2020 The JetBrains Mono
      Project Authors, https://github.com/JetBrains/JetBrainsMono

Beide Schriften stehen unter der SIL Open Font License, Version 1.1:
https://scripts.sil.org/OFL

Eingebunden werden sie ueber assets/css/fonts.css. Enthalten sind nur die
Subsets "latin" und "latin-ext"; fuer weitere Schriftsysteme muessten die
entsprechenden Subsets ergaenzt werden.
